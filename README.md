# 🌀 ПЛМ — пространство «политики любительского мазохизма»

Личный информационно-медиа сайт на Django для двоих: правила пятничного мероприятия с
пунктами/подпунктами/терминами, список наказаний, прогресс отработки и достижения.
Интерфейс — в духе Discord: рельса слева, каналы, лента сообщений, участники справа.

## Что внутри

| Канал | Что там |
|---|---|
| `#правила-мазохизма` | ПЛМ: состояния (сос), тиктоковское/дополнительное сос, ос/оп |
| `#оон` | Общее определение наказания: допускаемые наказания и правила выполнений |
| `#определения` | Глоссарий: `[[ос]]` в текстах правил подсвечивается подсказкой |
| `#список-наказаний` | Предложения и одобренные наказания (одобренные убрать нельзя — правило ООН) |
| `#колесо` | Весовое колесо (у визуальных новелл — малый шанс), кручение = кол |
| `#прогресс` | Мероприятия (т, ос → оп), калькулятор пятницы, отработки с прогрессом |
| `#достижения` | Выдаются автоматически, когда наказание достигнуто (отработано) |
| `#подсос` | Варианты подсоса; при ДОПОЛНИТЕЛЬНОМ сос выбирается ровно один |

Все расчёты — из правил: количество ос на одно оп зависит от числа тиктоков
(1/2/3 ос), <200 т → +ДОПОЛНИТЕЛЬНОЕ сос, >700 т → делить пополам на два мероприятия.
Сериалы: 2 серии за оп при сериях ≤35 мин, иначе 1 серия за оп. Фильмы: 1–3 оп по метражу.
Визуальная новелла: одна любая концовка.

## Быстрые правки

Сайт открыт для просмотра, но правки защищены общим ключом — замок 🔒 в левом нижнем углу.
Ключ по умолчанию: `friday`.

* сообщения правятся прямо в ленте (карандаш → Ctrl+Enter сохранить, Esc отмена);
* термины, подсосы, наказания, мероприятия — карточки с карандашом и быстрыми формами;
* счётчики т/ос — кнопками `+/-`, отработки тоже;
* глубокие правки — встроенная админка Django (`/admin/`, суперпользователь ниже).

Разметка сообщений: `**жирный**`, `*курсив*`, `++подчёркнутый++`, `~~зачёркнутый~~`,
`[[термин]]`, `[текст](ссылка)`, `---` разделитель, `> цитата`, `## заголовок`, списки `1.` / `-`.

## Запуск

```bash
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py seed            # наполнить правилами и примерами (или --reset)
python3 manage.py createsuperuser  # для админки (по желанию)
python3 manage.py runserver 0.0.0.0:8000
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `FDZHTT_EDIT_CODE` | `friday` | Ключ режима правок |
| `FDZHTT_SECRET_KEY` | генерируется в `.django-secret` | Секрет Django |
| `FDZHTT_DEBUG` | `1` | `0` — режим продакшена |

## Публичный запуск (в общем доступе)

1. Задайте переменные окружения выше (`FDZHTT_DEBUG=0`, свой `FDZHTT_EDIT_CODE` и `FDZHTT_SECRET_KEY`).
2. `python3 manage.py migrate && python3 manage.py seed`
3. `python3 manage.py collectstatic`
4. Запустите через gunicorn: `gunicorn config.wsgi -b 0.0.0.0:8000` (за reverse-proxy типа nginx/Caddy).
5. База — SQLite (`db.sqlite3`), её достаточно для личного использования; бэкап — просто копия файла.

Сменить контент можно и руками: `python3 manage.py seed --reset` пересоздаёт стартовые правила,
а всё дальнейшее живёт в базе и правится на сайте.
